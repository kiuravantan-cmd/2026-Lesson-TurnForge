# 問4：型と代入する値

## 作る・直す内容
damageはintのまま、代入する値を直す。ダメージは12。文字列変換関数を使わない。HPは12以上。

数値は0〜1000000の整数です。

## 使い方

問題ごとに別のコンソールアプリを作成します。最初は講師と一緒にQ01を作成します。
画像付きの[プロジェクト作成手順](../../README.md)をGitHubで参照してください。
配布ZIPにはソースコードだけが入っています。この問題文は.csファイルの先頭でも読めます。

1. Visual Studio 2022でQ04という名前のC#コンソールアプリを作成する。.NET 8.0を選び、「最上位レベルのステートメントを使用しない」にチェックする。
2. 最初のHello WorldをCtrl+F5で実行する。
3. 配布されたQ04.cs全体を、自分のQ04プロジェクトのProgram.cs全体へ貼り付ける。既存のMainへ追記しない。
4. エラーを直し、【原因】【対応方法】【エラー番号・内容】をコメントへ記入する。
5. 保存してCtrl+F5で実行する。ブレークポイントを使う場合はF5。
6. Mainへ自分の例を1つ以上追加し、選んだ理由・実行前の予想・結果をコメントへ記入する。
7. 完成したProgram.csは、このプロジェクトに保存して残す。次の問題は新しいプロジェクトで作成する。

## 提出

Q04プロジェクトのProgram.csを提出用フォルダーへコピーし、Q04.csという名前で提出します。
コードと説明コメントの両方を含めます。口頭説明や別の解答用紙は使いません。
配布元の未実装コードと回答を取り違えないでください。

最初はコンパイルエラーが出ます。修正してから実行します。
