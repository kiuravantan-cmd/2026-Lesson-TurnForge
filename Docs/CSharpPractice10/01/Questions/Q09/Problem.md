# 問9：HPが最も少ない敵

## 作る・直す内容
HP0を除外し、最小HPの敵の添字を返す。同点なら先にある敵。対象なしは-1。空配列に対応。nullは渡されない。

数値は0〜1000000の整数です。

Linqは使用しないこと。

## 使い方

問題ごとに別のコンソールアプリを作成します。最初は講師と一緒にQ01を作成します。
画像付きの[プロジェクト作成手順](../../README.md)をGitHubで参照してください。
配布ZIPにはソースコードだけが入っています。この問題文は.csファイルの先頭でも読めます。

1. Visual Studio 2022でQ09という名前のC#コンソールアプリを作成する。.NET 8.0を選び、「最上位レベルのステートメントを使用しない」にチェックする。
2. 最初のHello WorldをCtrl+F5で実行する。
3. 配布されたQ09.cs全体を、自分のQ09プロジェクトのProgram.cs全体へ貼り付ける。既存のMainへ追記しない。
4. 関数を実装し、【処理の説明】【条件が必要な理由】をコメントへ記入する。
5. 保存してCtrl+F5で実行する。ブレークポイントを使う場合はF5。
6. Mainへ自分の例を1つ以上追加し、選んだ理由・実行前の予想・結果をコメントへ記入する。
7. 完成したProgram.csは、このプロジェクトに保存して残す。次の問題は新しいプロジェクトで作成する。

## 提出

Q09プロジェクトのProgram.csを提出用フォルダーへコピーし、Q09.csという名前で提出します。
コードと説明コメントの両方を含めます。口頭説明や別の解答用紙は使いません。
配布元の未実装コードと回答を取り違えないでください。

配布コードの関数の中身は未実装です。仮の戻り値や空の処理を完成させます。
