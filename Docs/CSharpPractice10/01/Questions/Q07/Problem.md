# 問7：最大HPまで回復

## 作る・直す内容
HPに回復量を加え、最大HPを超えないようにする。0 <= HP <= 最大HP、最大HPは1以上。

数値は0〜1000000の整数です。問7の加算もint内に収まります。

## 使い方

問題ごとに別のコンソールアプリを作成します。最初は講師と一緒にQ01を作成します。
画像付きの[プロジェクト作成手順](../../README.md)を参照してください。

1. Visual Studio 2022でQ07という名前のC#コンソールアプリを作成する。.NET 8.0を選び、「最上位レベルのステートメントを使用しない」にチェックする。
2. 最初のHello WorldをCtrl+F5で実行する。
3. 配布されたQ07.cs全体を、自分のQ07プロジェクトのProgram.cs全体へ貼り付ける。既存のMainへ追記しない。
4. 関数を実装し、【処理の説明】【条件が必要な理由】をコメントへ記入する。
5. 保存してCtrl+F5で実行する。ブレークポイントを使う場合はF5。
6. Mainへ自分の例を1つ以上追加し、選んだ理由・実行前の予想・結果をコメントへ記入する。
7. 完成したProgram.csは、このプロジェクトに保存して残す。次の問題は新しいプロジェクトで作成する。

## 提出

Q07プロジェクトのProgram.csを提出用フォルダーへコピーし、Q07.csという名前で提出します。
コードと説明コメントの両方を含めます。口頭説明や別の解答用紙は使いません。
配布元の未実装コードと回答を取り違えないでください。

配布コードの関数の中身は未実装です。仮の戻り値や空の処理を完成させます。
